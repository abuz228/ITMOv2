# Требования к сервису подписчиков

## Существующее поведение

Модуль `service.py` хранит подписчиков в множестве `subscribers = set()`.

### `subscribe(name)`

- Нормализует имя через `strip()`.
- Пустое имя (или имя, пустое после нормализации) вызывает `ValueError("empty name")`.
- Добавляет нормализованное имя в `subscribers`.
- Повторная подписка на то же имя не создаёт дубликатов.
- Возвращает нормализованное имя.

## Будущие фичи

Фичи ниже описаны, но **пока не реализованы**.

### Feature A — `unsubscribe(name)`

- Нормализует имя через `strip()`.
- Пустое имя (или имя, пустое после нормализации) вызывает `ValueError("empty name")`.
- Если подписчик существует: удаляет его из `subscribers` и возвращает `True`.
- Если подписчика нет: возвращает `False` и не изменяет состояние.

### Feature B — `is_subscribed(name)`

- Нормализует имя через `strip()`.
- Пустое имя (или имя, пустое после нормализации) вызывает `ValueError("empty name")`.
- Возвращает `True`, если подписчик есть, и `False`, если его нет.
- Не изменяет состояние (`subscribers` остаётся прежним).
