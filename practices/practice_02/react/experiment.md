# ReAct

Файл ведёт OpenCode по вашим запросам. Агент записывает фактические результаты экспериментов и вносит изменения в связанные файлы. Свою оценку сообщайте ему в чате; вручную заполнять шаблон не нужно.

- Артефакт Практики 1: `practices/practice_01/problem.md`, раздел «Метрики».
- Модель: VseLLM / openai/gpt-5.
- Цель: проверить, можно ли воспроизвести текущие метрики M1 и M2 по имеющимся артефактам и найти только реально подтверждённые проблемы.
- Разрешённые действия: читать `problem.md`, `context.md`, `prompts.md`, `results/P1-01.txt`, `results/P1-02.txt`; сопоставлять значения метрик с этими файлами; предлагать правку только при обнаружении конкретной проблемы.
- Запрещено: менять файлы без оценки студента; придумывать baseline/пороги/требования; использовать внешние источники; считать `possible` как `confirmed`.
- Условие остановки: если текущий раздел «Метрики» воспроизводим и противоречий нет — остановиться без предложения изменений.

Предложи правку в `problem.md` только если найдена конкретная проблема. Если раздел «Метрики» воспроизводим и противоречий нет — остановись без изменений.
