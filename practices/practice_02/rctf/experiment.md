# R.C.T.F.

Файл ведёт OpenCode по вашим запросам. Агент записывает фактические результаты экспериментов и вносит изменения в связанные файлы. Свою оценку сообщайте ему в чате; вручную заполнять шаблон не нужно.

- Артефакт Практики 1: `practices/practice_01/problem.md`, раздел «Метрики».
- Цель: сделать правила M1/M2 однозначными; исключить выдумывание baseline моделью; явно указать источники/момент измерения; не считать `possible` как `confirmed`; обеспечить проверяемость по сохранённым P1-01/P1-02 и оценке студента.

## Запрос (RCTF)

Role

Вы — ассистент по улучшению SDLC-артефактов. Ваша задача — аккуратно переписать раздел «Метрики» так, чтобы методика была однозначной и проверяемой, без выдумывания чисел и порогов.

Context

- Артефакт: practices/practice_01/problem.md, раздел «Метрики».
- Модель: VseLLM / openai/gpt-5.
- Источники фактов: сохранённые результаты запусков P1-01 и P1-02 (results/P1-01.txt, results/P1-02.txt) и оценка студента по подтверждённости рисков.
- Ограничения:
  - Не добавлять новые метрики, работать только с M1 и M2.
  - Не выдумывать baseline или пороги; опираться на сохранённые результаты и оценку студента.
  - Не считать статус `possible` как `confirmed` для M2.
  - Итог должен быть проверяем по P1-01/P1-02 и оценке студента.
  - Сохранить краткость и читаемость таблицы.

Task

Перепишите раздел «Метрики» следующим образом:
1. Сформулируйте однозначные правила подсчёта для M1 и M2.
2. Укажите источники данных и момент измерения.
3. Для M1 допустимо указать текущее значение, если оно однозначно следует из сохранённых результатов; для M2 текущие значения не придумывать и не переоценивать автоматически — они берутся только из оценки студента (классификации замечаний confirmed|possible). Если классификация ещё не зафиксирована — явно укажите это в таблице как «по оценке студента (не пересчитывать автоматически)».
4. Не добавляйте новых метрик и не меняйте смысл существующих.

Format

Верните только один блок — готовый раздел Markdown с заголовком `## Метрики`, правилами и таблицей (без лишних комментариев). Не меняйте другие разделы файла.
