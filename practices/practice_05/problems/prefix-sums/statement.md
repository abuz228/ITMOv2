# Range Sum Queries

Дан массив целых чисел. Ответьте на запросы суммы на отрезке `[l, r]`. Индексация начинается с единицы.

## Входные данные

Первая строка содержит `n` и `q`. Вторая строка содержит массив. Далее записаны `q` пар `l r`.

## Выходные данные

Для каждого запроса выведите сумму элементов с индексами от `l` до `r` включительно.
