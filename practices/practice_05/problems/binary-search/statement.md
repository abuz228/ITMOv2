# Binary Search

Дан отсортированный массив и несколько запросов. Для каждого запроса выведите индекс первого вхождения искомого числа или `-1`, если числа нет. Индексация начинается с нуля.

## Входные данные

Первая строка содержит `n` и `q`. Вторая строка содержит `n` чисел массива. Далее следуют `q` искомых чисел.

## Выходные данные

Для каждого запроса выведите ответ в отдельной строке.
