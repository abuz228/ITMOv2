# Integration-проверки

Файл ведёт OpenCode. Обсудите с агентом содержание и проверьте предложенный diff. Все дополнения и исправления поручайте агенту в чате.

| Связь компонентов | Что может сломаться | Как воспроизводим | Ожидаемый результат | Подтверждение |
|---|---|---|---|---|
| Передача diff от пользователя к AI | Потеря/искажение входа | Передать diff с известной цитатой | AI возвращает Risks с evidence, содержащим эту цитату | Сопоставление цитаты из ответа с исходным diff |
| Формирование результата AI | Превышение 3 рисков или отсутствие evidence | Передать diff с несколькими изменениями | Не более 3 Risks; у каждого Risk есть evidence | Подсчёт количества и проверка наличия цитат |
| ReviewService → LLM | Искажение diff в prompt или потеря данных | Передать diff и зафиксировать сформированный prompt | Prompt содержит diff без искажения; формат ожидаемого ответа сохраняется | Сопоставление prompt и diff; структура ответа соответствует Master Prompt |

## Как использовали AI

- Строка в [`prompts.md`](prompts.md): Master Prompt v1; P1-02.
- Что проверил студент и какие исправления поручил агенту: убедился, что интеграционные проверки следуют из согласованного контекста; без добавления новых систем или интеграций.
