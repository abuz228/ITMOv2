# Use cases и user stories

## Первый рабочий сценарий

**Когда** разработчик или ревьюер передаёт diff PR, **система** (AI‑помощник) анализирует diff и возвращает Summary, максимум 3 риска с доказательствами и список Checks, **а пользователь получает** проверяемые замечания и принимает решение.

Не входит в этот сценарий:

- approve/merge; изменение кода; запуск тестов; любые решения за человека.

## Use case

| Поле | Значение |
|---|---|
| Актор | Разработчик/ревьюер PR |
| Триггер | Появился diff PR, требуется провести первичный анализ |
| Предусловия | Доступен текстовый diff (git diff) |
| Основной результат | Summary, до 3 Risks с файлами/строками и цитатами, и Checks для воспроизведения |
| Ошибка или отказ | Вход недостаточен для подтверждения — риски помечаются как possible или AI запрашивает человека |

```mermaid
sequenceDiagram
    actor User as Ревьюер
    participant AI as AI‑помощник
    User->>AI: Передаёт diff PR
    AI-->>User: Summary; Risks (<=3) с цитатами; Checks
    User-->>User: Проверяет результат и принимает решение
```

## User stories и acceptance criteria

```gherkin
Feature: AI‑помощник ревьюера PR
  As a разработчик/ревьюер PR
  I want получить краткий и доказательный первичный результат по одному diff
  So that я быстрее выявлял риски и понимал, какие проверки выполнить

  # Acceptance criteria (встроены в сценарии):
  # - Summary присутствует и кратко описывает изменение
  # - В Risks не более 3 пунктов
  # - Каждый риск содержит file/path, location (если уместно), finding и evidence (цитату из diff)
  # - Риск помечается status: confirmed|possible в зависимости от наличия доказательств в diff
  # - Checks содержат 1–3 шага, напрямую следующих из найденных рисков
  # - Нет утверждений вне diff; AI не approve/merge и не меняет код

  Scenario: Позитивный — валидный diff
    Given у меня есть валидный текстовый diff PR
    When я передаю diff AI‑помощнику
    Then я получаю Summary по изменению
    And я получаю не более 3 Risks
    And каждый Risk содержит file/path и evidence (цитату из diff)
    And я получаю Checks с шагами воспроизведения, связанными с найденными рисками

  Scenario: Негативный — недостаточный вход
    Given diff неполный или недостаточный для подтверждения риска
    When я передаю такой diff AI‑помощнику
    Then риски помечены как possible или AI указывает на недостаточность входа
    And в ответе нет утверждений вне diff

  Scenario: Граничный — более трёх потенциальных проблем
    Given diff содержит более трёх потенциальных проблем
    When я передаю diff AI‑помощнику
    Then в ответе не более 3 наиболее значимых Risks
    And каждый Risk подкреплён цитатами из diff или помечен как possible
    And Checks следуют из найденных рисков
```
